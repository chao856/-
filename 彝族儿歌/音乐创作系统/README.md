# 音乐创作系统

## 系统架构

1. **关键词分析模块(NLP)**
   - 歌词生成
   - 音乐风格匹配

2. **编曲生成模块**

3. **合成与输出模块**
   - 音频输出
   - MIDI输出

## 使用说明

1. 安装依赖：`pip install -r requirements.txt`
2. 运行主程序：`python main.py`

## 模块说明

- `lyrics_generator/`: 歌词生成模块
- `style_matcher/`: 音乐风格匹配模块
- `arrangement/`: 编曲生成模块
- `synthesis/`: 音频合成模块
